Validated Reliability Work

What We Inspected and Implemented

Implemented and verified on the physical prototype; candidate navigation tuning is clearly separated from the active default comparison.

Navigation

Narrow-space profile is a candidate, not the active baseline

Map analysis produced narrow_improved4.yaml with 0.18 m inflation versus the 0.50 m default. Current physical runs still use the default baseline.

Audio Isolation

Recording no longer locks announcements

arecord and aplay use independent process slots and UI state. Live concurrent recording and announcement playback passed.

Self-Recovery

Bounded playback timeout and forced cleanup

Timeout = WAV duration + 5 seconds, bounded to 10–180 seconds; wedged playback is forcibly cleaned up.

State Reconciliation

The robot is authoritative, not the browser

A 1-second heartbeat corrects the UI; a 6-second watchdog releases stale locks; request-ID retries are de-duplicated on the bridge.
